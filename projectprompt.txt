1. PRODUCT
============================================================

The product is a multi-tenant SaaS platform that allows organizations to:

1. Configure AI voice agents.
2. Configure company/business information.
3. Configure sales behavior.
4. Configure customer-support behavior.
5. Configure languages.
6. Configure voice.
7. Configure agent personality.
8. Manage customers/contacts.
9. Upload contacts through Excel/CSV.
10. Create outbound calling campaigns.
11. Select an AI agent for a campaign.
12. Select a phone number.
13. Start outbound calls.
14. Receive inbound calls.
15. Let AI answer inbound calls.
16. Conduct multilingual conversations.
17. Understand the customer's spoken language.
18. Respond naturally in that language.
19. Handle language switching during a conversation.
20. Store transcripts.
21. Store call metadata.
22. Store call outcomes.
23. Create leads.
24. Schedule callbacks.
25. Transfer/escalate to humans.
26. Execute backend tools/functions.
27. View campaign performance.
28. View call history.
29. View analytics.
30. Eventually support billing/usage metering.

The AI voice runtime uses:

- Gemini Live API for realtime AI conversation
- Exotel for telephony and call streaming

The dashboard is the control plane.

The realtime voice infrastructure is the runtime plane.

These two concerns MUST remain architecturally separated.
