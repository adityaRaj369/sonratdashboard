# @sonrat/web

Next.js 15 App Router dashboard for the Sonrat control plane.

## Scripts

```bash
pnpm --filter @sonrat/web dev
pnpm --filter @sonrat/web build
pnpm --filter @sonrat/web typecheck
pnpm --filter @sonrat/web lint
```

## Env

```
NEXT_PUBLIC_API_BASE_URL=http://localhost:4000
```
